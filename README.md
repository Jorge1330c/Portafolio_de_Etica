# Brújula Ética

Portafolio digital de identidad ética profesional del equipo **Los Estoicos** para el curso Ética y Deontología Profesional (HUM-010, UCSUR, 2026-2).

Construido con [Astro](https://astro.build) reutilizando el diseño del blog de Realidad Nacional, con tema oscuro por defecto y estética "ópalo".

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # sitio estático en dist/
npm run preview
```

Guía de edición y pendientes: ver `CLAUDE.md`.
